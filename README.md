# DependencyVisualisation

CLI-инструмент визуализации зависимостей пакетов Rust (Cargo), вариант № 2.
На этапе 1 реализованы чтение INI-конфигурации, проверка параметров и их вывод в формате ключ-значение.

## Настройки

Все пять параметров обязательны в секции `[visualizer]`:

```ini
[visualizer]
package_name = serde
repository = https://index.crates.io/
test_mode = false
ascii_tree = false
max_depth = 3
```

| Параметр | Описание |
| --- | --- |
| `package_name` | Имя Cargo-пакета; в тестовом режиме - заглавные латинские буквы. |
| `repository` | HTTP(S)-URL репозитория или путь к существующему читаемому файлу в тестовом режиме. |
| `test_mode` | Режим тестового репозитория: `true` или `false`. |
| `ascii_tree` | Признак вывода ASCII-дерева: `true` или `false`. На этапе 1 проверяется и выводится. |
| `max_depth` | Максимальная глубина анализа: целое число от `0`. На этапе 1 проверяется и выводится. |

Глубина корневого пакета принята равной `0`. Относительные пути задаются от рабочего каталога процесса.
Путь к INI передается флагом `-config`; по умолчанию используется `tests/example.ini`.
Ошибки чтения и проверки конфигурации завершают приложение через `panic` с сообщением о причине.

## Сборка и тесты

Требуются Go 1.26.4 или новее и Make. Команды выполняются из корня репозитория:

```sh
make build
make test
```

Собранное приложение находится в `bin/visualiser`.
Модульные тесты конфигурации расположены в пакете `config`, примеры INI - в `tests`.

## Примеры запуска

Запуск с корректной конфигурацией и выводом всех пяти параметров:

```sh
make run
```

Выбор INI и демонстрация ошибки имени пакета:

```sh
make run CONFIG=tests/invalid_package.ini
```

Ожидается `panic` с сообщением `неверное значение package_name: "bad/name"`.
Другие примеры ошибок: `tests/invalid_repository.ini`, `tests/invalid_test_mode.ini`,
`tests/invalid_ascii_tree.ini`, `tests/invalid_max_depth.ini`.
